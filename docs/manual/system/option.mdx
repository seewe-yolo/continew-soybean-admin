---
title: 系统配置
description: 网站、密码、邮件、登录和三方能力参数的运行时修改与重置，无需重启生效。
---

系统配置把运行期需要调整的参数（站点信息、密码策略、邮件服务器、登录开关和三方能力）放到页面上维护，修改即写库生效，不需要重启服务。功能入口在「系统管理 -> 系统配置」，后端接口前缀为 `/system/option`，对应 `OptionController`。参数存储在 `sys_option` 表，每条记录包含类别、键、值与默认值。

## 参数类别

参数类别由 `OptionCategoryEnum` 定义。

| 类别 | 页面分组 | 说明 |
|:-----|:---------|:-----|
| `SITE` | 网站配置 | 系统名称、描述、版权、备案号、图标、LOGO |
| `PASSWORD` | 安全配置 | 密码错误锁定、有效期、历史密码、长度与复杂度 |
| `MAIL` | 邮件配置 | SMTP 服务器、账号、SSL |
| `LOGIN` | 登录配置 | 登录验证码开关 |
| `THIRD_PARTY` | 三方能力配置 | 阿里云 OCR 与微信支付 V3 配置 |

<Callout type="info">
短信配置走 `sys_sms_config` 表，存储配置走 `sys_storage` 表，客户端配置走 `sys_client` 表，均不在 `sys_option` 中。前端「系统配置」菜单下的短信、存储、客户端三个页签分别对应[短信管理](./sms.mdx)、[存储管理](./storage.mdx)、[客户端配置](./client.mdx)。
</Callout>

## 内置参数清单

初始化脚本写入的参数键与默认值如下（`sys_option` 表）。

### 网站配置（SITE）

| 键 | 默认值 | 说明 |
|:---|:-------|:-----|
| `SITE_TITLE` | ContiNew Admin | 显示在浏览器标题栏和登录界面的系统名称 |
| `SITE_DESCRIPTION` | 持续迭代优化的前后端分离中后台管理系统框架 | 用于 SEO 的网站元描述 |
| `SITE_COPYRIGHT` | Copyright © 2022 - present ContiNew Admin 版权所有 | 页面底部版权声明 |
| `SITE_BEIAN` | 空 | 工信部 ICP 备案编号 |
| `SITE_FAVICON` | /favicon.ico | 浏览器标签页图标 |
| `SITE_LOGO` | /logo.svg | 登录页与导航栏图标 |

网站配置经 `GET /system/common/dict/option/site` 公开读取，前端标题、LOGO、备案号均取自该接口，不需要登录。

### 安全配置（PASSWORD）

| 键 | 默认值 | 说明 |
|:---|:-------|:-----|
| `PASSWORD_ERROR_LOCK_COUNT` | 5 | 连续登录失败达到该次数锁定账号（0 表示禁用锁定） |
| `PASSWORD_ERROR_LOCK_MINUTES` | 5 | 锁定后自动解锁的分钟数 |
| `PASSWORD_EXPIRATION_DAYS` | 0 | 密码强制修改周期，0 表示永不过期 |
| `PASSWORD_EXPIRATION_WARNING_DAYS` | 0 | 过期前提前提醒天数，0 表示不提醒 |
| `PASSWORD_REPETITION_TIMES` | 3 | 禁止使用最近 N 次历史密码 |
| `PASSWORD_MIN_LENGTH` | 8 | 密码最小长度 |
| `PASSWORD_ALLOW_CONTAIN_USERNAME` | 1 | 是否允许密码包含正序或倒序用户名 |
| `PASSWORD_REQUIRE_SYMBOLS` | 0 | 是否要求密码包含特殊字符 |

### 邮件配置（MAIL）

| 键 | 默认值 | 说明 |
|:---|:-------|:-----|
| `MAIL_PROTOCOL` | smtp | 邮件发送协议 |
| `MAIL_HOST` | smtp.126.com | 邮件服务器地址 |
| `MAIL_PORT` | 465 | 服务器端口 |
| `MAIL_USERNAME` | charles7c@126.com | 发件人邮箱账号 |
| `MAIL_PASSWORD` | 空 | 邮箱授权码 |
| `MAIL_SSL_ENABLED` | 1 | 是否启用 SSL/TLS 加密 |
| `MAIL_SSL_PORT` | 465 | SSL 端口 |

邮件配置是邮箱验证码登录（`EmailLoginHandler`）与邮件通知的前提，`MAIL_PASSWORD` 未配置时发信会失败。

### 登录配置（LOGIN）

| 键 | 默认值 | 说明 |
|:---|:-------|:-----|
| `LOGIN_CAPTCHA_ENABLED` | 1 | 是否启用登录验证码 |

### 三方能力配置（THIRD_PARTY）

| 键 | 默认值 | 说明 |
|:---|:-------|:-----|
| `ALIYUN_OCR_ENABLED` | 0 | 是否启用阿里云 OCR |
| `ALIYUN_OCR_ACCESS_KEY_ID` | 空 | 阿里云 OCR 访问密钥 ID |
| `ALIYUN_OCR_ACCESS_KEY_SECRET` | 空 | 阿里云 OCR 访问密钥 Secret，不回显，留空保存不会覆盖已保存值 |
| `ALIYUN_OCR_ENDPOINT` | ocr-api.cn-hangzhou.aliyuncs.com | 阿里云 OCR 服务地址 |

微信支付配置位于三方能力配置右侧区域，页面在桌面端按两列展示，后续新增三方能力继续按列扩展。

| 键 | 默认值 | 说明 |
|:---|:-------|:-----|
| `WECHAT_PAY_ENABLED` | 0 | 是否启用微信支付 V3 |
| `WECHAT_PAY_APP_ID` | 空 | 微信支付公众号或小程序 AppID |
| `WECHAT_PAY_MCH_ID` | 空 | 微信支付商户号 |
| `WECHAT_PAY_MCH_SERIAL_NO` | 空 | 商户证书序列号 |
| `WECHAT_PAY_PRIVATE_KEY` | 空 | `apiclient_key.pem` 私钥内容，不回显，留空保存不会覆盖已保存值 |
| `WECHAT_PAY_API_V3_KEY` | 空 | API v3 密钥，不回显，留空保存不会覆盖已保存值 |
| `WECHAT_PAY_NOTIFY_URL` | 空 | 支付结果通知地址，必须为外网可访问的 HTTPS 地址 |
| `WECHAT_PAY_PUBLIC_KEY_ID` | 空 | 微信支付公钥 ID，配合平台公钥验签 |
| `WECHAT_PAY_PUBLIC_KEY` | 空 | 微信支付平台公钥 PEM 原文，不是商户公钥 |

当前支持普通商户 JSAPI/小程序支付，采用 WxJava 公钥模式。先在商户平台获取商户私钥、商户证书序列号、API v3 密钥及微信支付公钥与公钥 ID，再启用支付。通知地址须为不带查询参数的 HTTPS 地址。每个区域独立保存、重置，重置会清除该区域已保存的密钥并关闭能力。

## 接口与权限

`OptionController` 不走 CRUD 套件，只提供三个接口，按页面分组拆分权限码。

| 功能 | 接口 | 权限码（满足其一即可） |
|:-----|:-----|:-----------------------|
| 查询参数列表 | `GET /system/option` | `system:siteConfig:get` / `system:securityConfig:get` / `system:loginConfig:get` / `system:mailConfig:get` / `system:thirdPartyConfig:get` |
| 修改参数 | `PUT /system/option` | 对应分组的 `system:*Config:update` |
| 重置参数 | `PATCH /system/option/value` | 对应分组的 `system:*Config:update` |

修改接口按提交的键值批量更新；重置接口把指定参数恢复为 `default_value`。
三方配置额外按数据库中的实际类别校验 `system:thirdPartyConfig:get/update`，其他配置页的权限不能访问或修改支付配置。修改请求体不写入操作日志。

<Callout type="warn">
`sys_option` 没有逻辑删除字段，参数记录由初始化脚本写入，不要直接删行。新增自定义参数类别需要同步扩展 `OptionCategoryEnum` 与前端页面，属于代码级改动。
</Callout>
